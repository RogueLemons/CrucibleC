# The Crucible C Project

> “The good news about computers is that they do what you tell them to do. The bad news is that they do what you tell them to do.”
>
> — Ted Nelson

The Crucible C Project is a collection of tools and experiments exploring safer, clearer ways to write and reason about C.

Includes:
- [AlloyCTranspiler (Prototype)](AlloyCTranspiler_Prototype): adds extra keywords to C for safety and readability
- [IronCLib (Beta)](IronCLib): a quick-and-easy drop-in header library for safer C code
- [SteelCLib (upcoming)](SteelCLib): a bigger, better version of IronCLib with more flexibility at complexity cost
- [WorkshopC (Alpha)](WorkshopC): a code parser for safer and clearer code to follow a mold of coding
